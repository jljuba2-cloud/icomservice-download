 전화 한 통이면 됩니다.
 프로그램을 미리 받으실 필요가 없습니다.

────────────────────────────────────────────
 1단계  빠른 지원 열기
────────────────────────────────────────────
 ① 키보드에서 아래 세 키를 동시에 누릅니다.

        [Ctrl] + [Windows] + [Q]

    · 시작 메뉴에서 "빠른 지원"을 검색해도 됩니다.
    · 단축키가 안 되면: Windows 키 + R →
      "quickassist" 입력 → Enter

 ② "빠른 지원" 창이 열립니다.

────────────────────────────────────────────
 2단계  6자리 코드 입력
────────────────────────────────────────────
 운영자가 전화로 불러주는 6자리 숫자를
 "도우미의 보안 코드" 칸에 입력하고 [제출]을
 누릅니다.

 → 다음 화면에서 [허용]을 누릅니다.
 → 운영자가 화면을 보며 도와드립니다.

 · 고객님은 Microsoft 계정이 필요 없습니다.
 · 운영자는 비밀번호를 절대 묻지 않습니다.
 · 화면은 고객님이 허용한 동안만 공유됩니다.

────────────────────────────────────────────
 3단계  설치 + 8자리 코드 (운영자가 함께)
────────────────────────────────────────────
 ① 운영자가 아이컴 전용 프로그램을 설치합니다.
    "이 PC에 원격지원 프로그램을 설치할까요?"
    창이 뜨면 [동의하고 설치]를 한 번 누릅니다.

 ② 화면에 8자리 코드 입력칸이 뜨면
    운영자가 불러주는 숫자를 입력하고
    [연결]을 누릅니다.

 ③ 오른쪽 위에 빨간 [원격 지원 중] 창이
    보이면 연결된 것입니다.

────────────────────────────────────────────
 끌 때 / 문제가 생기면
────────────────────────────────────────────
 · 언제든 트레이의 [즉시 중지]를 누르면
   연결이 완전히 끊깁니다.
 · 다음부터는 바탕화면의
   [아이컴 화면 지원] 아이콘을 누르고
   8자리 숫자만 입력하시면 됩니다.
 · 잘 안 되면 전화 주세요.
