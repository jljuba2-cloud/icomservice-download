자주 묻는 질문

명령 복사가 뭐예요?

설치 명령을 클립보드에 복사하는 버튼입니다. 복사한 뒤 Windows 키 + R을 누르고 Ctrl+V → Enter를 누르면 설치가 시작됩니다. 파일을 따로 받지 않아도 됩니다.

8자리 코드는 어디에 입력하나요?

설치 후 자동으로 실행되는 아이컴 원격지원 창에 입력합니다. 코드는 운영자가 전화로 불러드리며, 1회용입니다.

명령 복사가 안 되면?

위의 실행파일(EXE) 또는 압축파일(ZIP)을 직접 받아 실행하세요. 이 경우 Windows SmartScreen 경고가 한 번 뜰 수 있습니다.

디펜더·V3·알약이 막아요

프로그램 파일 자체는 Windows Defender 정밀 검사에서 바이러스로 탐지되지 않았습니다. 다만 서명이 없어서 “인터넷에서 받아 바로 실행”하는 동작을 보안 프로그램이 막을 수 있습니다.

백신을 끄거나 예외 폴더를 만들지 마세요. 위의 실행파일(EXE) 또는 압축파일(ZIP)로 받은 뒤 실행하거나, 010-7390-3507로 전화 주세요.

설치 후 경고가 뜨나요?

명령으로 설치한 경우에는 경고가 뜨지 않습니다. EXE/ZIP으로 직접 받은 경우 첫 실행 때 한 번 경고가 뜰 수 있고, 이후에는 뜨지 않습니다.
